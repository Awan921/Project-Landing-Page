# Project: Landing Page

This is my second project as part of **The Odin Project** curriculum. The project is a complete landing page for a fictional restaurant called "Awan Restaurant".

## Live Preview

[View Live Website](https://awan921.github.io/Project-Landing-Page/)

## Skills Demonstrated

- HTML boilerplate structure
- Semantic HTML elements (`<header>`, `<section>`, `<footer>`)
- CSS Flexbox (header, hero, information, CTA sections)
- CSS typography (Montserrat font)
- CSS colors and backgrounds
- Git workflow (atomic commits, push to GitHub)
- GitHub Pages deployment

## Sections

1. **Header** - Logo and navigation links
2. **Hero** - Main heading, subtext, and call-to-action button
3. **Information** - Three cards with images and text
4. **Quote** - Inspirational quote with author
5. **Call to Action** - Sign-up prompt with button
6. **Footer** - Copyright information

## What I Learned

- How to structure a complete web page from a design
- How to use Flexbox for layout (main axis, cross axis, justify-content, align-items)
- How to use Google Fonts (Montserrat)
- How to commit early and often (atomic commits)
- How to deploy a website using GitHub Pages
